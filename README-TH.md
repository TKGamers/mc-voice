# ZoHight Voice — คู่มือแอดมิน

## ระบบประกอบด้วย
- **เซิร์ฟเวอร์เสียง** (Render) : ส่งต่อเสียงเฉพาะคนที่อยู่ในระยะ + ระบบโทรศัพท์
- **แอดออน BP + RP** (เซิร์ฟเวอร์เกม) : ส่งตำแหน่ง ไอคอนเหนือชื่อ เมนูไมค์ โทรศัพท์ วงแสดงระยะเสียง
- **แอป Android** : ไมค์ทำงานเบื้องหลัง ตัดเสียงรบกวน กันเสียงสะท้อน
- **หน้าเว็บ** : สำหรับ iPhone / PC

## ตั้งค่าที่แอดมินแก้เองได้
| ที่ไหน | ค่า | ความหมาย |
|---|---|---|
| Render > Environment | `API_KEY` | รหัสลับ ต้องตรงกับ config.js ของแอดออน |
| Render > Environment | `MAX_RANGE` | ระยะเสียงสูงสุดที่ผู้เล่นตั้งได้ (บล็อก) ค่าเริ่มต้น 30 ตั้งได้ 5-500 |
| GitHub `mc-voice` > `config.json` | `texts`, `theme` | แก้ข้อความทุกจุดและสีของหน้าแอป/เว็บ ไม่ต้องสร้างแอปใหม่ |
| BP `scripts/config.js` | `MAX_RANGE` | ค่าสำรองของเมนูในเกม (ให้ตรงกับ Render) |
| BP `scripts/config.js` | `RING_SECONDS` | แสดงวงระยะเสียงกี่วินาที |
| BP `scripts/config.js` | `PHONE_ENABLED` / `PHONE_AUTO_GIVE` | เปิดโทรศัพท์ / แจกอัตโนมัติ |

### แก้ข้อความและสีของแอป/เว็บ
1. GitHub > repo `mc-voice` > ไฟล์ `config.json` > ไอคอนดินสอ
2. แก้ข้อความด้านขวาของ `"ชื่อ":` ที่อยู่ในเครื่องหมายคำพูด (อย่าลบเครื่องหมาย `"` หรือ `,`) `{name}` คือชื่อผู้เล่นที่ระบบใส่ให้
3. สีใช้รหัส เช่น `#8b5cf6` ในหมวด `theme`
4. Commit changes แล้วรอ Render อัปเดต 2-3 นาที เปิดแอป/เว็บใหม่จะเห็นผล

## ไอเทมในเกม
- **ไมค์** (แจกอัตโนมัติ) : แตะ = เมนูตั้งค่า (ไมค์ หู ระยะ ความดังไมค์ ปรับอัตโนมัติ) / ย่อตัว + แตะ = แสดงวงระยะเสียง
- **โทรศัพท์** : แจกด้วยคำสั่ง `/give @s voice:phone` แตะเพื่อโทร รับสาย วางสาย คู่สายได้ยินกันไม่จำกัดระยะ คนข้างๆ ได้ยินเฉพาะเสียงของเรา

## ไอคอนเหนือชื่อผู้เล่น
ปลั๊กขีดแดง = ยังไม่เชื่อม | ไมค์ขาวหนา = กำลังพูด | ไมค์เทา = ไม่ได้พูด | ไมค์ขีดทอง = ปิดไมค์ | หูฟังขีดทอง = ปิดหู | ไอคอนโทรศัพท์ = อยู่ในสาย

## กันเสียงสะท้อน
ถ้าไม่ได้ใช้หูฟัง แอปจะเข้าโหมดโทรศัพท์ของ Android ให้เอง (เหมือนแอปโทรทั่วไป) ใช้หูฟังจะได้ผลดีที่สุด

## อัปเดตระบบ
1. **เซิร์ฟเวอร์เสียง** : อัปโหลดทั้ง 7 ไฟล์ใน `zohight-server-files.zip` ขึ้น repo `mc-voice` ทับของเดิม
2. **แอดออนเกม** : ทับโฟลเดอร์ BP ด้วย `voice-BP-ready.zip` ติดตั้ง RP เวอร์ชัน 1.0.2 จาก `voice-RP-ready.zip` (ถ้ามี world_resource_packs.json ให้แก้ version เป็น [1, 0, 2]) แล้วรีสตาร์ตเซิร์ฟเวอร์เกม
3. **แอป Android** : อัปโหลด `zohight-app.zip` ทับใน repo `zohight-voice-app` แล้วรัน Build ใหม่
