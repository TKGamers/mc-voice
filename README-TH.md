# ZoHight Voice — คู่มือติดตั้งและตั้งค่า

## ภาพรวมระบบ
- **เซิร์ฟเวอร์เสียง** (Render) : ส่งต่อเสียงเฉพาะคนที่อยู่ในระยะ
- **แอดออน BP + RP** (เซิร์ฟเวอร์เกม) : ส่งตำแหน่งผู้เล่น แสดงไอคอนเหนือชื่อ ไอเทมไมค์
- **แอป Android** : ไมค์ทำงานเบื้องหลังได้
- **หน้าเว็บ** : สำหรับ iPhone / PC (iPhone ต้องเปิดหน้าเว็บค้างไว้)

## ค่าที่แอดมินปรับได้

| ที่ไหน | ตัวแปร | ความหมาย |
|---|---|---|
| Render > Environment | `API_KEY` | รหัสลับ ต้องตรงกับ config.js ของแอดออน |
| Render > Environment | `MAX_RANGE` | ระยะเสียงสูงสุดที่ผู้เล่นตั้งได้ (บล็อก) ค่าเริ่มต้น 30 ตั้งได้ 5-500 |
| config.js (BP) | `MAX_RANGE` | ค่าสำรองของเมนูในเกมตอนที่ยังต่อเซิร์ฟเวอร์เสียงไม่ได้ ควรตั้งให้เท่ากับ Render |
| config.js (BP) | `DEFAULT_RANGE` | ระยะเสียงเริ่มต้นของผู้เล่นใหม่ |
| config.js (BP) | `UPDATE_TICKS` | ความถี่ส่งตำแหน่ง (5 = 4 ครั้ง/วินาที) |

เปลี่ยน `MAX_RANGE` บน Render แล้วกด Save (Render จะรีสตาร์ตเอง) เมนูในเกมเว็บและแอปจะปรับตามเอง ไม่ต้องสร้างแอปใหม่

## ไอคอนเหนือชื่อผู้เล่น
| ไอคอน | ความหมาย |
|---|---|
| ปลั๊กขีดฆ่าสีแดง | ยังไม่ได้เชื่อมระบบเสียง |
| ไมค์ขาวหนา | กำลังพูด |
| ไมค์เทา | เชื่อมแล้ว ไม่ได้พูด |
| ไมค์ขีดฆ่าสีทอง | ปิดไมค์ |
| หูฟังขีดฆ่าสีทอง | ปิดหู |

ต้องติดตั้ง Resource Pack (RP) ถึงจะเห็นไอคอน

## ตัดเสียงรบกวน / กันเสียงสะท้อน
- **ตัดเสียงรบกวน** ปิด / กลาง / แรง : ตัดเสียงคงที่ เช่น พัดลม แอร์ เสียงซ่า (ตัวเลือก "แรง" ตัดมากสุด แต่เสียงพูดอาจบางลง)
- **กันเสียงสะท้อน** อัตโนมัติ / เปิด / ปิด : ใช้ลำโพงให้เลือกเปิด ใช้หูฟังเลือกปิดหรืออัตโนมัติ (แอปตรวจหูฟังให้เอง)
- ใช้หูฟังจะได้ผลดีที่สุด เพราะเสียงสะท้อนเกิดจากไมค์อัดเสียงลำโพง

## อัปเดตระบบ (ลำดับที่แนะนำ)
1. **เซิร์ฟเวอร์เสียง** : อัปโหลดไฟล์ใน `zohight-server-files.zip` (6 ไฟล์) ขึ้น GitHub repo `mc-voice` ทับของเดิม Render จะอัปเดตเอง
2. **แอดออนเกม** : ทับไฟล์ในโฟลเดอร์ BP ด้วย `voice-BP-ready.zip` และติดตั้ง/อัปเดต RP ด้วย `voice-RP-ready.zip` (เวอร์ชัน 1.0.1) แล้วรีสตาร์ตเซิร์ฟเวอร์เกม
3. **แอป Android** : อัปโหลด `zohight-app.zip` ทับใน repo `zohight-voice-app` แล้วรัน Build ใหม่ จะได้ APK เวอร์ชันใหม่ ติดตั้งทับของเดิมได้เลย
